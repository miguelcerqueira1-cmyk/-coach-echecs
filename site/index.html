    Explications Claude

    Données Lichess (Opening Explorer)

    Créez-le sur lichess.org → Préférences → Jetons d’accès API, sans cocher aucune permission. Il reste sur cet appareil. Inutile si le relais Cloudflare est configuré.

    Vidéos YouTube (facultatif)

    Gratuite (≈ 100 recherches par jour). console.cloud.google.com → créer un projet → « API et services » → activer YouTube Data API v3 → Identifiants → Créer une clé API → restreindre la clé aux référents HTTP https://miguelcerqueira1-cmyk.github.io/* et à l’API YouTube. Elle reste sur cet appareil. Sans clé, l’application propose des liens de recherche YouTube par langue.

    Mes données (changer d’appareil)

    Exportez votre progression, vos révisions, vos réglages et vos analyses dans un fichier, puis importez-le sur votre autre appareil (téléphone ↔ ordinateur). Le jeton Lichess, le code d’accès et la clé YouTube ne sont jamais exportés : ressaisissez-les ici.
